# Camera + ISP + 图像质量调优 + 稳定性测试

基于i.MX6ULL + OV5640的Camera嵌入式开发项目3

## 项目概述

本项目在项目2（Camera预览 + 图像处理）的基础上，实现了：

1. **图像质量调优** - 通过I2C调整OV5640寄存器参数
2. **ISP处理** - 色彩校正、Gamma校正、自动曝光/白平衡
3. **稳定性测试** - 72小时连续运行测试
4. **性能分析** - 帧率、延迟、CPU、内存统计

## 功能特性

### 1. OV5640图像调优
- 曝光控制
- 增益调整
- 白平衡设置
- 锐度调节

- 饱和度调整
- 批量测试不同参数组合

- 色彩校正矩阵 (CCM)

### 3. 稳定性测试

- 帧率监控

- 内存泄漏检测

- 异常自动恢复

### 4. 性能分析
- 实时帧率统计

- 性能报告生成


### 2. 调优模式
```bash
./camera_tuning -m tuning
```

交互命令：
- `e <value>` - 设置曝光 (十六进制)
- `g <value>` - 设置增益 (十六进制)
- `s <value>` - 设置锐度 (十六进制)
- `d <value>` - 设置降噪 (十六进制)
- `a` - 运行自动调优
- `r` - 恢复默认参数
- `p` - 打印当前参数
- `q` - 退出

## 技术要点

### 1. OV5640寄存器
- 通过I2C读写
- 曝光寄存器：0x3500-0x3502
- 增益寄存器：0x350A-0x350B
- 白平衡寄存器：0x3400-0x3405
- 锐度寄存器：0x5308
- 降噪寄存器：0x5309
- 饱和度寄存器：0x5300

### 2. ISP处理流程
```
YUYV输入 → 色彩校正 → Gamma校正 → 白平衡 → YUYV输出
```

### 3. 稳定性测试指标
- 帧率稳定性
- 丢帧率 < 1%
- 内存泄漏检测
- CPU占用 < 80%
- 连续运行72小时无崩溃

### 4. 性能分析指标
- 平均帧率
- 最小/最大帧率
- 平均延迟
- 最大延迟
- CPU使用率
- 内存峰值

## 开发环境

- 硬件：正点原子i.MX6ULL阿尔法板 + OV5640摄像头
- 系统：Linux
- 工具链：arm-linux-gnueabihf-gcc
- 依赖：pthread, math

## 注意事项

1. OV5640的I2C地址为0x3C
2. 需要root权限访问I2C设备
3. 稳定性测试需要长时间运行，建议使用nohup
4. 性能测试结果可能因硬件环境而异
5. 调优参数需要根据实际场景调整
